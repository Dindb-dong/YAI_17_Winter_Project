PROJECT OVERVIEW

Adaptive Video Search Engine
for Context & Sequence

자연어 쿼리를 기반으로 영상의 장면과 시퀀스(구간)를 찾는 Text-to-Video Temporal Retrieval 프로젝트입니다. 현재 로직은 CLIP 중심 검색 + EMA 기반 구간 정밀화를 핵심으로 구성됩니다.

핵심 목표

Scene → Sequence

단일 장면 검색에서 연속 맥락 구간 검색으로 확장

핵심 전략

2-Stage Search

q/3 quick scan + q full scan, Top-K 기반 필터링

핵심 고도화

EMA Refinement

anchor 중심 좌/우 경계 추정으로 시간 구간 정밀화

WHY THIS PROJECT

프로젝트 시작 이유

실제 사용자의 불편과 연구 공백을 동시에 해결하는 방향으로 기획했습니다.

영화나 유튜브를 보다가 특정 장면이 떠올라도 정확한 시점은 기억나지 않는 경우가 많습니다. 단순 키워드 검색만으로는 맥락 기반 탐색이 어렵기 때문에, 텍스트 의미를 이해하는 영상 검색이 필요했습니다.
Text-to-Video Temporal Retrieval 관련 논문은 존재하지만, 실제 프로젝트에서 장면 + 시퀀스를 함께 안정적으로 찾는 구현은 제한적이었습니다. 그래서 본 팀은 실사용 가능한 수준으로 문장 분해 - 시간 구간 추정 - 경계 안정화 를 연결하는 로직을 직접 설계했습니다.
EVOLUTION

프로젝트 발전 과정

1차(장면 검색) → 2차(구간 검색) → 3차(경계 안정화) 순서로 발전했습니다.

1차: 장면 검색

Sliding Window + CLIP 기반 Top-K 후보 추출

2차: 시퀀스 검색

Top-K anchor 중심 좌/우 탐색, EMA로 구간 정밀화

3차: 안정화

경계 과확장/과축소 문제를 임계 기반 수렴 로직으로 완화

BLIP-2 기본경로를 제거하고 CLIP 중심으로 단순화했습니다. `step`을 도입해 윈도우를 중첩시켰고, 평균 점수보다 강건한 `max` 기반 점수화로 바꿨습니다. 또한 Gemini로 한국어 쿼리를 영어 동작 문장으로 분할/변환했습니다.
단일 하락점이 아니라 다중 하락 후보를 비교해 경계를 선택했습니다. `q/3` 빠른 스캔 이후 Top-K 하위 70% 미만 window를 스킵하는 filtering mode를 추가해 긴 영상에서 추론 시간을 크게 줄였습니다.
반복 확장만으로는 구간이 짧거나 길어지는 문제가 있어, top window `max score` 대비 고득점 프레임 구간을 초기 경계로 잡고 기준을 점진적으로 올리며 구간을 수렴시키는 방식을 적용했습니다.

입력/분석
사용자 쿼리를 Gemini로 분할/영문화하고 실패 시 규칙 기반 fallback으로 복구합니다.
검색 최적화
q/3 빠른 샘플링과 Top-K 기반 필터링으로 긴 영상에서 연산량을 줄입니다.
결과 정밀화
전역 유사도 타임라인에 EMA를 적용해 구간 경계를 안정화합니다.
FUTURE ROADMAP

향후 발전 가능 포인트

현재 로직을 기반으로 정확도·속도·운영성을 더 끌어올릴 수 있는 실질적인 확장 항목입니다.

현재는 고정값 중심의 하이퍼파라미터를 사용합니다. 영상 길이, 장면 전환 밀도, 쿼리 타입(단일/시퀀스)에 따라 drop ratio와 임계치를 자동 튜닝하면 경계 품질을 더 안정화할 수 있습니다.
Gemini 분할 결과의 품질을 정량화하고, 분할 오류가 실제 retrieval 성능에 미치는 영향을 추적하는 지표 체계를 만들면 모델/프롬프트 개선의 방향이 명확해집니다.
캡션 편향과 비용 문제를 줄이기 위해, 경량 텍스트-비전 리랭커를 후보 단계에만 선택적으로 적용하는 전략이 유효합니다. 추론 비용 대비 정확도 향상을 목표로 실험할 수 있습니다.
캐시, 분산 처리, 구간 인덱싱(사전 계산) 등을 추가하면 다수 영상 라이브러리 환경에서도 실시간에 가까운 검색 UX를 제공할 수 있습니다.
SUMMARY

정리

이 프로젝트는 “텍스트로 장면을 찾는 문제”를 넘어 “맥락이 있는 시간 구간을 찾는 문제”로 확장해, 실제 사용자 경험에 가까운 Text-to-Video Retrieval 파이프라인을 구현했습니다.

핵심 성과

- 쿼리 분할/영문화 + 단일/시퀀스 분리 검색
- 2단계 샘플링과 filtering mode로 속도 최적화
- EMA 기반 경계 정밀화 및 안정화 로직 확보
